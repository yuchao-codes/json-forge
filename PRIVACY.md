# Privacy Policy / 隐私政策

**Extension / 扩展名称**: JSON Forge
**Last Updated / 最后更新**: 2026-11-24

---

## English

### Overview

JSON Forge is a browser extension that formats, minifies, searches, and compares JSON in a dedicated tab of your browser. **We do not collect, store, or transmit any user data.** All processing happens entirely on your local device.

### Data Collection

This extension does **not** collect any user data, including:

- No browsing history, web page content, or bookmarks
- No cookies or any other tracking technologies
- No personal information, identifiers, or account data
- No analytics, telemetry, or error reporting

### Permissions

This extension requests **no permissions** (`permissions` and `host_permissions` are empty in its manifest). It does not access your browser tabs, cookies, storage, or any websites. Clicking the extension icon only opens the extension's own local workbench page in a new tab.

### Data Storage

This extension does **not** use any storage mechanism — no `chrome.storage`, `localStorage`, `sessionStorage`, `IndexedDB`, or cookies. The JSON you paste or open is kept only in memory while the workbench page is open, and is permanently discarded when you close the tab.

### Network Communication

This extension makes **no network requests** of any kind. It contains no analytics SDKs and communicates with no remote servers. It works fully offline.

### Remote Code

This extension does **not** load, execute, or fetch any code from remote servers. All code and resources are bundled inside the extension package.

### Third-Party Sharing

Since no data is collected, no data is ever shared with, sold to, or transferred to any third party.

### Contact

If you have any questions about this privacy policy, please open an issue at the extension's repository on GitHub.

## 中文

### 概述

JSON Forge 是一款浏览器扩展，用于在浏览器的独立标签页中格式化、压缩、搜索和比较 JSON。**本扩展不收集、不存储、不传输任何用户数据。** 所有处理均完全在您的本地设备上完成。

### 数据收集

本扩展**不**收集任何用户数据，包括：

- 不读取浏览历史、网页内容或书签
- 不使用 Cookie 或任何其他跟踪技术
- 不收集个人信息、标识符或账户数据
- 无分析统计、遥测或错误上报

### 权限说明

本扩展**不申请任何权限**（manifest 中的 `permissions` 和 `host_permissions` 均为空）。它不会访问您的浏览器标签页、Cookie、存储或任何网站。点击扩展图标仅会在新标签页中打开扩展自带的本地工作台页面。

### 数据存储

本扩展**不使用任何存储机制**——不使用 `chrome.storage`、`localStorage`、`sessionStorage`、`IndexedDB` 或 Cookie。您粘贴或打开的 JSON 仅在工作台页面打开期间保存在内存中，关闭标签页后即被彻底丢弃。

### 网络通信

本扩展**不发出任何网络请求**。它不包含任何分析统计 SDK，也不与任何远程服务器通信，可完全离线运行。

### 远程代码

本扩展**不从远程服务器加载、执行或获取任何代码**。所有代码和资源均打包在扩展安装包内。

### 第三方共享

由于不收集任何数据，因此也绝不会与任何第三方共享、出售或转让数据。

### 联系方式

如您对本隐私政策有任何疑问，请在本扩展的 GitHub 仓库中提交 Issue。
