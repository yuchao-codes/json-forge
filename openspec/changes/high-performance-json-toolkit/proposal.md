# Proposal

## Why

使用现有 JSON 工具处理较大的接口响应时，浏览器会卡顿。需要一个本地运行的浏览器扩展，让用户在转换、搜索和比较大文档时仍能操作界面，并能下载完整结果。

## What Changes

- 从扩展图标打开独立的 JSON 工作台。首版面向 Chrome 和 Edge，支持粘贴与打开本地 UTF-8 文件。
- 提供严格 JSON 格式化和压缩，保留数字、字段顺序和重复键。提供 JSON 字符串转义与单层反转义。
- 提供左右对比和差异导航。比较前统一缩进，输出行级差异，可下载完整的 `.diff` 文件。
- 在输入、转换结果和 Diff 两侧提供全文搜索，支持大小写切换、匹配计数和前后跳转。预览之外的内容也能定位。
- 支持复制转换结果和下载完整结果。大文档按片段显示，计算任务可取消，超出处理预算时显示明确状态。

## Capabilities

### New Capabilities

- `json-workbench` 提供扩展内的本地 JSON 转换、比较、全文搜索和结果导出。

### Modified Capabilities

## Impact

- 沿用现有 WXT + Vue 3 项目，扩展入口打开工作台页面，并调整模板中现有的示例入口。
- 新增工作台界面、文档状态和 Dedicated Web Worker，引入适合大文档的编辑器及可限制计算预算的差异库。
- 扩展资源随扩展打包，文档处理和导出均在浏览器本地完成。
- 使用 1 MiB、10 MiB 和 50 MiB 的合成样本验证长单行、深层嵌套、大范围差异、搜索定位及运行中的界面响应。
