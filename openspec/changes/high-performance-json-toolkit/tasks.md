- [x] 1.1 添加 WXT 工作台页面，把扩展图标连接到该页面，并移除模板弹窗和示例内容脚本。验证实际安装的扩展能从图标打开工作台，生成的清单无需网站访问权限。
- [x] 1.2 实现粘贴、UTF-8 文件输入和文档版本管理。验证非法编码保留上次输入，两侧输入互不覆盖，并且文件导入可离线工作。

## 2. 转换、预览与导出

- [x] 2.1 实现基于原文 token 的严格 JSON 校验、两空格格式化和压缩。用大整数、指数、重复键、顶层标量、转义字符串、非法数字、尾逗号、非法控制字符和额外顶层值验证输出或错误位置。
- [x] 2.2 实现 JSON 字符串转义和单层反转义。验证含引号、反斜杠、换行和 Unicode 的文本往返，以及错误输入和多层字符串的行为。
- [x] 2.3 接入 CodeMirror 6 和有界预览。验证超长单行、超多行结果和文件输入均可显示有限片段，并保有对应的原文位置。
- [x] 2.4 实现完整结果复制及文件下载。用大结果逐字节校验下载内容，并验证剪贴板写入成功和被拒绝时的状态。

- [x] 3.1 实现 Worker 内的 JSON 归一化与有预算的行级 Diff。验证纯空白差异、字段换序、无效侧和超时行为。
