# Spec Delta

## Purpose

让开发者直接在浏览器中处理接口响应和本地 JSON 文件，执行转换、对比、全文搜索和导出，并在处理大文档时保持工作台可操作。

## ADDED Requirements

### Requirement: 本地工作台与文档输入

扩展 SHALL 在 Chrome 和 Edge 中从扩展图标打开独立的工作台标签页，接受粘贴文本和用户选取的本地 UTF-8 文件，并在浏览器本地处理文档内容。

#### Scenario: 打开工作台并导入

- **WHEN** 用户通过扩展图标打开工作台并选取 UTF-8 文件
- **THEN** 工作台使用该文件内容作为对应输入，可在离线状态执行操作

#### Scenario: 文件编码错误

- **WHEN** 所选文件包含无效 UTF-8 字节
- **THEN** 工作台提示编码错误并保留上一次有效输入

### Requirement: 保留原文的格式化与压缩

工作台 SHALL 校验严格 JSON。格式化使用两个空格缩进，压缩移除字符串以外的 JSON 空白。两种操作均保留字符串和数字字面量、对象字段顺序及重复键。

#### Scenario: 保留数字和字符串字面量

- **WHEN** 用户转换包含 `9007199254740993`、指数记法、重复键或转义字符串的合法 JSON
- **THEN** 除字符串以外的空白，输出与原文的 token 序列完全一致

#### Scenario: 接受顶层标量

- **WHEN** 用户格式化顶层为字符串、数字、布尔值或 `null` 的合法 JSON
- **THEN** 操作成功并保留标量原文

#### Scenario: 拒绝非法 JSON

- **WHEN** 用户转换含尾逗号、注释、非法转义或第二个顶层值的输入
- **THEN** 工作台显示语法错误及其输入位置，并保留原始输入

### Requirement: JSON 字符串转义

工作台 SHALL 将任意文本转义为带外层引号的合法 JSON 字符串，并允许将一个合法的 JSON 字符串字面量反转义一层。

#### Scenario: 文本往返

- **WHEN** 用户转义含双引号、反斜杠、换行和 Unicode 字符的文本并反转义该结果
- **THEN** 得到与原文相同的文本，保留原文中的换行和空白

#### Scenario: 保留剩余转义层

- **WHEN** 用户反转义包含两层 JSON 字符串转义的输入
- **THEN** 仅去掉最外层，剩余文本可由用户再次执行反转义

#### Scenario: 拒绝非字符串输入

- **WHEN** 用户尝试反转义非法字符串或合法 JSON 对象
- **THEN** 工作台提示输入必须是合法的 JSON 字符串，并保留原始输入

### Requirement: JSON 行级对比

工作台 SHALL 校验两侧 JSON 并统一缩进后按行比较，展示左右内容和增删差异，并支持前后差异跳转。比较保留对象字段顺序、数组顺序和字面量写法。

#### Scenario: 仅有缩进差异

- **WHEN** 两侧 JSON token 序列一致且只在字符串外的空白不同
- **THEN** 对比显示无差异

#### Scenario: 对象字段换序

- **WHEN** 左右对象字段取值相同但顺序不同
- **THEN** 对比显示行级差异，并允许跳转到对应差异

#### Scenario: 一侧语法错误

- **WHEN** 任一侧 JSON 无效
- **THEN** 工作台标出对应侧及错误位置，并显示该次对比失败

### Requirement: 所选文档的全文搜索

工作台 SHALL 支持通过 `Ctrl+F` 或 `Cmd+F` 打开搜索，按字面匹配原始输入、转换结果或 Diff 中用户选定的一侧。搜索支持切换大小写匹配，显示当前匹配位置和匹配总数，并提供上一处与下一处跳转。

#### Scenario: 当前文档的大小写匹配

- **WHEN** 当前文档包含 `Foo` 和 `foo`，用户用 `foo` 搜索并切换大小写匹配
- **THEN** 区分大小写时匹配一处，忽略大小写时匹配两处，跳转定位并高亮当前匹配

#### Scenario: 预览范围外的匹配

- **WHEN** 用户搜索的词只出现在大文档当前预览之外
- **THEN** 搜索统计包含该词，用户可以跳转并查看匹配附近的内容

#### Scenario: 切换 Diff 搜索侧

- **WHEN** 用户在 Diff 中选择另一侧继续搜索
- **THEN** 匹配计数和跳转仅依据新选定侧的文档内容

#### Scenario: 关键词或文档更新

- **WHEN** 旧搜索尚未完成，用户更换关键词、清空搜索或替换文档
- **THEN** 停止旧搜索，清除已失效的计数与高亮，后续只展示当前搜索的结果

### Requirement: 复制与下载完整结果

工作台 SHALL 支持复制和下载完整的转换结果，并在成功生成完整差异后提供统一差异格式的 `.diff` 下载。

#### Scenario: 下载超出预览范围的转换结果

- **WHEN** 用户下载大文档的转换结果且当前仅显示有限预览
- **THEN** 下载包含完整转换内容，格式化和压缩结果使用 `.json`，字符串转义和反转义结果使用 `.txt`

#### Scenario: 复制转换结果

- **WHEN** 用户发起复制且浏览器接受剪贴板写入
- **THEN** 剪贴板收到完整转换结果

#### Scenario: 浏览器拒绝写入剪贴板

- **WHEN** 用户发起复制且浏览器拒绝剪贴板写入
- **THEN** 工作台提示失败并保留完整结果的下载入口

#### Scenario: 下载统一差异文件

- **WHEN** 用户下载一次成功完成且包含差异的对比结果
- **THEN** `.diff` 应用到统一缩进后的左侧文本可重建统一缩进后的右侧文本

### Requirement: 大文档操作期间保持界面可用

工作台 SHALL 在处理大文档时限制呈现的文本量，并允许用户取消正在运行的操作。输入、输出或计算超过适用预算时，工作台 SHALL 告知所受限制并保留用户输入。

#### Scenario: 转换运行中取消

- **WHEN** 用户在转换大文件时滚动工作台并点击取消
- **THEN** 界面响应上述操作，原始输入仍可使用，已取消任务的结果不会覆盖当前页面

#### Scenario: 对比超过预算

- **WHEN** 两份高差异文档的比较达到计算预算
- **THEN** 工作台提示本次对比未完成，保留两侧文档供查看和搜索，并禁用该次 `.diff` 导出

#### Scenario: 结果超过可显示范围

- **WHEN** 转换成功但完整结果超过预览范围
- **THEN** 工作台标明当前是有限预览，仍可搜索、定位和下载完整结果
